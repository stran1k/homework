

## Общая характеристика

Предметной областью проектируемой базы данных является деятельность билетных касс театра (кинотеатра) по продаже и бронированию билетов на сеансы. Организация проводит показы фильмов (спектаклей) в нескольких залах. Каждый зал имеет схему с пронумерованными местами, которые делятся на категории (партер, амфитеатр, балкон, VIP-ложа) и различаются по стоимости.

Основные задачи, которые решает касса:

- ведение схемы залов с нумерацией мест по рядам;
- формирование репертуара: какое произведение, в каком зале, когда и по какой цене показывается;
- бронирование мест зрителями на ограниченный срок;
- продажа (выкуп) билетов с учётом категории зрителя (обычный, льготный, VIP);
- контроль занятости мест, чтобы исключить продажу одного места дважды;
- учёт выручки и подготовка отчётности по сеансам, кассирам и категориям зрителей.

## Описание бизнес-процессов

1. **Подготовка репертуара.** Администратор добавляет в каталог фильмы (спектакли) и назначает сеансы: дата, время начала, зал, базовая цена.
2. **Бронирование.** Зритель обращается в кассу (лично или по телефону), выбирает сеанс и свободные места. Кассир оформляет бронь на конкретные места с указанием контактных данных и срока действия. Если бронь не выкуплена до истечения срока, она аннулируется, а места освобождаются.
3. **Продажа билетов.** Кассир выбирает сеанс и место, определяет категорию зрителя и рассчитывает итоговую цену с учётом скидки. После оплаты оформляется билет. Если место было забронировано, билет оформляется на основании брони.
4. **Возврат билета.** При возврате билет аннулируется, место снова становится свободным.
5. **Отчётность.** Руководство получает данные о загрузке залов, выручке за период и количестве проданных билетов по категориям зрителей.

## Участники процесса

| Участник | Роль |
|---|---|
| Зритель | Бронирует места и покупает билеты |
| Кассир | Оформляет брони, продаёт билеты, принимает возвраты |
| Администратор | Ведёт репертуар, залы, цены и категории зрителей |
| Руководитель | Анализирует отчёты по выручке и загрузке |

## Описание сущностей (таблиц)

**Зал** — помещение, в котором проходят сеансы.

| Атрибут | Описание |
|---|---|
| Код зала | Уникальный идентификатор |
| Название | Например, «Большой зал» |
| Вместимость | Общее число мест |

**Категория места** — ценовая группа мест.

| Атрибут | Описание |
|---|---|
| Код категории | Уникальный идентификатор |
| Название | Партер, балкон, VIP-ложа |
| Коэффициент цены | Множитель к базовой цене сеанса |

**Место** — конкретное кресло в зале.

| Атрибут | Описание |
|---|---|
| Код места | Уникальный идентификатор |
| Код зала | Ссылка на зал |
| Код категории | Ссылка на категорию места |
| Ряд | Номер ряда |
| Номер места | Номер в ряду |

**Произведение (фильм/спектакль)** — единица репертуара.

| Атрибут | Описание |
|---|---|
| Код произведения | Уникальный идентификатор |
| Название | Название фильма или спектакля |
| Жанр | Драма, комедия и т. д. |
| Длительность | В минутах |
| Возрастное ограничение | Например, 12+ |

**Сеанс** — показ произведения в определённом зале в определённое время.

| Атрибут | Описание |
|---|---|
| Код сеанса | Уникальный идентификатор |
| Код произведения | Ссылка на произведение |
| Код зала | Ссылка на зал |
| Дата и время начала | Когда проходит сеанс |
| Базовая цена | Цена стандартного билета |

**Категория зрителя** — тип посетителя, определяющий скидку.

| Атрибут | Описание |
|---|---|
| Код категории | Уникальный идентификатор |
| Название | Взрослый, студент, пенсионер, ребёнок, инвалид, VIP |
| Размер скидки, % | Скидка от цены (для VIP может быть 0 или наценка) |
| Требуемый документ | Что нужно предъявить для льготы |

**Клиент** — зритель, оформляющий бронь (при желании и покупку).

| Атрибут | Описание |
|---|---|
| Код клиента | Уникальный идентификатор |
| ФИО | Фамилия, имя, отчество |
| Телефон | Контактный номер |
| E-mail | Адрес электронной почты |

**Сотрудник (кассир)** — работник, оформляющий операции.

| Атрибут | Описание |
|---|---|
| Код сотрудника | Уникальный идентификатор |
| ФИО | Фамилия, имя, отчество |
| Должность | Кассир, администратор |
| Логин | Для входа в систему |

**Бронирование** — предварительное закрепление места за клиентом.

| Атрибут | Описание |
|---|---|
| Код брони | Уникальный идентификатор |
| Код сеанса | Ссылка на сеанс |

| Код клиента | Ссылка на клиента |
| Код сотрудника | Кто оформил бронь |
| Дата создания | Когда оформлена |
| Срок действия | До какого момента держится бронь |

**Билет** — факт выкупа места.

| Атрибут | Описание |
|---|---|
| Код билета | Уникальный идентификатор |
| Код сеанса | Ссылка на сеанс |
| Код места | Ссылка на место |
| Код категории зрителя | Ссылка на категорию зрителя |

## Связи между сущностями

- Один **зал** содержит много **мест** (1:М).
- Одна **категория места** присваивается многим **местам** (1:М).
- Одно **произведение** показывается на многих **сеансах** (1:М).
- В одном **зале** проходит много **сеансов** (1:М).
- На один **сеанс** оформляется много **броней** и **билетов** (1:М).
- Одно **место** может быть в разных **билетах** и **бронях**, но на разных сеансах (1:М).
- Один **клиент** может иметь много **броней** (1:М).
- Одна **категория зрителя** применяется ко многим **билетам** (1:М).
- Один **сотрудник** оформляет много **броней** и **билетов** (1:М).
- Одна **бронь** приводит не более чем к одному **билету** (1:1).

## Ограничения и бизнес-правила

1. Место на конкретном сеансе может быть продано или забронировано только один раз, то есть пара «сеанс + место» уникальна среди действующих билетов и броней.
2. Место в зале однозначно определяется парой «ряд + номер места».
3. Сеансы в одном зале не должны пересекаться по времени.
4. Бронь действует ограниченное время (например, до начала сеанса минус 1 час), после чего аннулируется автоматически.
5. Итоговая цена билета = базовая цена сеанса × коэффициент категории места × (1 − скидка категории зрителя).
6. Льготные категории зрителей обязаны подтверждаться документом при получении билета.
7. Билет на прошедший сеанс нельзя продать или вернуть.
8. Возраст зрителя должен соответствовать возрастному ограничению произведения.

## Входная и выходная информация

**Входная информация:** данные о залах и схемах мест; каталог произведений; расписание сеансов; справочники категорий мест и зрителей; данные клиентов; параметры броней и продаж.

**Выходная информация:** билет (сеанс, зал, ряд, место, цена); подтверждение брони; схема зала со статусами мест (свободно, забронировано, продано); репертуарный план; отчёты о выручке, загрузке залов и продажах по категориям зрителей.
